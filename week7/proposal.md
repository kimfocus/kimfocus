# [RoutineFit] 개인 맞춤형 운동 루틴 및 수행 기록 앱 기획안

## 1. 문제 정의
- 기존 운동 앱들은 기능이 너무 복잡하여 초보자가 운동 직후 빠르게 기록하기 어려움.
- 본인이 수행한 운동 세트와 중량을 직관적으로 확인하고 다음 세트를 준비할 수 있는 간결한 인터페이스가 필요함.

## 2. 대상 사용자
- **첫 사용자**: 헬스장에 처음 다니기 시작하여 복잡한 통계보다 일일 세트/중량 기록이 최우선인 운동 초보자.

## 3. 핵심 가치
- 불필요한 단계 없이 앱 실행 후 3초 이내에 오늘 운동 세트 기록 시작.
- 최소한의 터치로 세트 수행 완료 체크 및 다음 중량 세팅.

## 4. MVP 범위
- **필수 포함 기능**: 
  - 운동 종목 등록 및 당일 루틴 생성
  - 세트별 중량(kg) 및 횟수(reps) 입력 및 완료 체크
  - 일자별 운동 수행 완료 기록 조회
- **보류/제외 기능 및 이유**: 
  - 커뮤니티 및 친구 공유 기능 (MVP 핵심 가치 검증에 불필요)
  - 칼로리 소모량 자동 계산 (정확도 확보 미흡 및 외부 API 연동 복잡성 증가)

## 5. 제약 사항
- **저장 방식**: LocalStorage (네트워크 연결 없이 오프라인 동작 보장)
- **실행 환경**: 모바일 웹 (React / PWA 대응) 및 Expo 기반 모바일 환경
- **개인정보 취급 범위**: 회원가입 없이 사용자 기기 내부 저장소만 이용 (개인정보 수집 없음)

## 6. 화면 및 데이터 구조
- **화면 구조**:
  1. 홈/메인: 오늘의 운동 목록 및 세트 체크리스트
  2. 운동 추가/수정: 운동 종목 선택 및 세트수/중량 지정
  3. 히스토리: 날짜별 운동 완료 내역 캘린더/리스트
- **데이터 구조**:
  - `Routine`: `{ id, date, exerciseList: [{ exerciseId, name, sets: [{ setNum, weight, reps, completed }] }] }`

## 7. 앱 인수 조건 (AC - Acceptance Criteria)

### AC 1: 정상 입력 - 세트 수행 기록 완료
- **행동**: 사용자가 '벤치프레스' 1세트(60kg, 10회)의 체크박스를 터치한다.
- **기대 결과**: 해당 세트 항목이 '완료' 상태로 전환(색상 변경 및 취소선)되며 로컬 저장소에 반영된다.
- **확인 방법**: 앱을 새로고침하거나 재실행해도 해당 세트가 완료 상태로 유지되는지 확인.

### AC 2: 잘못된 입력 handling - 음수 또는 비정상적인 값 입력
- **행동**: 중량 입력 칸에 `-50` 또는 문자를 입력하고 저장 버튼을 누른다.
- **기대 결과**: "올바른 양의 숫자를 입력해주세요" 경고 문구가 노출되고 데이터 저장이 거부된다.
- **확인 방법**: 입력 폼 하단에 에러 메시지가 뜨는지 확인하고 데이터베이스/로컬저장소에 저장되지 않는지 확인.

### AC 3: 빈 상태 (Empty State) - 등록된 운동이 없는 첫 진입
- **행동**: 앱을 처음 설치 및 실행하여 오늘 날짜의 기록 화면으로 이동한다.
- **기대 결과**: "등록된 운동 루틴이 없습니다. [운동 추가하기] 버튼을 눌러 첫 루틴을 만드세요" 안내 화면이 표시된다.
- **확인 방법**: 저장된 데이터를 모두 삭제(Clear LocalStorage) 후 메인 화면 진입 시 안내 문구와 추가 버튼이 보이고 오류가 나지 않는지 확인.

### AC 4: 예외 처리 / 외부 요청 실패 및 재시도
- **행동**: 네트워크 연결이 차단된(오프라인) 상태에서 운동 기록을 저장한다.
- **기대 결과**: 로컬 저장소에 선 저장된 후 "오프라인 모드입니다. 저장된 기록은 단말기에 유지됩니다" 메시지가 표시된다.
- **확인 방법**: 브라우저 개발자 도구에서 Network를 Offline으로 설정하고 기록 저장 후 정상 작동 여부 확인.
